# Сценарий демонстрации

Видео 3–5 минут с реальными Telegram, TMDB, DeepSeek и Google Calendar. Подменённые ответы в видео не используются.

## Подготовка

1. Все настройки заданы, `doctor --network` завершается успешно.
2. Свежая база: новый том или пустой `DATA_DIR`, чтобы показать первое знакомство.
3. Отдельный календарь Series Scout открыт в браузере рядом с Telegram.
4. Заранее выбран сериал с известной будущей датой сезона на TMDB, чтобы в календаре появилось событие.

## Сцены

| Время | Сцена | Что показать |
| --- | --- | --- |
| 0:00–0:30 | Проблема | Сериалов много, премьеры новых сезонов легко пропустить; Series Scout подбирает по вкусу и следит за датами. |
| 0:30–1:30 | Интервью | `/start` → рассказ о любимых и нелюбимых сериалах → выбор карточки с годом при неоднозначном названии → один-два уточняющих вопроса → итог и «Сохранить профиль». |
| 1:30–2:30 | Рекомендации | `/recommend` → карточки с описанием, ссылкой на TMDB и объяснением «Почему». |
| 2:30–3:00 | Обратная связь | «Смотрел» → «Понравилось» → пояснение; «Не интересно» на другой карточке; «В список» и `/list`. |
| 3:00–3:45 | Подписка | `/search` → сериал с будущим сезоном → «Следить за сезонами» → сообщение о календаре → событие на весь день в Google Calendar. |
| 3:45–4:30 | Проверка | `/sync` → «Изменений нет», повторная синхронизация не создаёт дубль; `/following` и `/status`. |

## Что проговорить

- Каталог и даты — только TMDB; неизвестную дату бот не прогнозирует.
- Модель выбирает только из переданных кандидатов, названия, даты и ссылки формирует код.
- Календарь — отдельный, события ведёт бот; отписка удаляет будущие события.
