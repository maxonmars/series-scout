# Инструкции для изменений

## Перед коммитом

```bash
npm run check
```

Команда должна пройти целиком: lint, typecheck, check:deps, test, build.

## Код

- Слои и запреты — в [ARCHITECTURE.md](ARCHITECTURE.md). Новое правило границ добавляется в `.dependency-cruiser.cjs`, а не описывается только словами.
- `process.env` и `process.argv` читаются только в `src/app/main.ts`; остальное получает конфигурацию параметрами.
- Типы SDK (grammY, openai, google-auth-library, `node:sqlite`) остаются в `src/adapters`. Внешние данные проверяются Zod на границе адаптера.
- Только стираемый синтаксис TypeScript: без `enum`, `namespace` и parameter properties. Относительные импорты — с расширением `.ts`.
- Новая настройка: описание в `src/app/settings.ts`, пояснение в `.env.example`, тест в `tests/cli.test.ts`. Секрет не помечается `public` и не выводится ни в отчётах, ни в текстах ошибок.
- Не создавать интерфейсы, сущности и адаптеры впрок: код появляется вместе со сценарием, который его использует.
- Изменение схемы SQLite — новая версия `SCHEMA_VERSION` и шаг миграции в `src/adapters/sqlite/database.ts`; существующие шаги не переписываются.
- Промпты — Markdown в `src/prompts`; формат ответа модели проверяется Zod-схемой в `src/adapters/deepseek`, при изменении меняются оба.

## Тесты

- Vitest, файлы `tests/**/*.test.ts`.
- Без внешней сети и настоящих credentials: внешние сервисы подменяются через интерфейсы `application`.
- Название теста описывает реальное поведение.

## Зависимости

- Версии фиксируются точно (`npm install --save-exact`), `package-lock.json` создаёт только npm.
- Без ORM, HTTP-фреймворков, отдельных SQLite-пакетов, axios и dotenv: хватает `node:sqlite`, `fetch` и `process.loadEnvFile`.

## Документация и тексты

- Документация, сообщения пользователю и тексты ошибок — на русском; идентификаторы и названия библиотек — в оригинале.
- Комментарии — 1–2 строки о неочевидном. Обоснования решений — в `ARCHITECTURE.md`.
- В README раздел «Текущее состояние» отражает только то, что реально работает в коммите.
- Устаревший факт исправляется на месте.
